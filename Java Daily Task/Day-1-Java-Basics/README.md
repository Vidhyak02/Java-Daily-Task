## ▶️ How to Run the Programs

**Step 1:** Install JDK 21 and configure the Java environment.

**Step 2:** Open the terminal in the Java-Solution folder.

**Step 3:** Compile the Java file.

```bash
javac Q01_HelloWorld.java
```

**Step 4:** Run the compiled program.

```bash
java Q01_HelloWorld
```

Repeat the same steps for the remaining programs using their respective class names.
